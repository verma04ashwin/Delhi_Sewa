# DelhiSewa Web

Public web platform for DelhiSewa.

## Purpose

DelhiSewa Web provides the public web experience for discovering local businesses, services, professionals, shops, and places.

## Repository Scope

This repository contains the implementation of the DelhiSewa Web platform.

It includes:

- Application source code
- Tests
- Configuration
- Technical documentation
- Development tooling
- Deployment configuration
