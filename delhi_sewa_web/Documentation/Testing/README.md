# Testing

Testing protects correctness, security, and maintainability.

## Testing Levels

- Unit tests
- Component tests
- Integration tests
- End-to-end tests

## Principles

- Test behavior rather than implementation details where practical.
- Test both successful and failure cases.
- Prioritize security-sensitive behavior.
- Prioritize critical user journeys.
- Avoid brittle tests.
- Keep tests maintainable.

## Continuous Integration

Required checks will eventually be enforced through CI before changes are merged.
