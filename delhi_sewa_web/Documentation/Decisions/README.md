# Technical Decisions

This directory records significant technical decisions for DelhiSewa Web.

## Record a Decision When

A decision materially affects:

- Architecture
- Security
- Data flow
- Authentication
- Authorization
- Dependencies
- Deployment
- Infrastructure
- Testing strategy
- Performance architecture

## Do Not Record

Do not create a decision record for every small implementation detail.

## Naming

Use:

`DEC-XXXX - Short Decision Name.md`

Example:

`DEC-0001 - Web Application Architecture.md`
