# DEC-0001 — Start With Jwala Nagar

**Date:** 2026-08-13

**Status:** Accepted

**Area:** Strategy / Geography

## Context

DelhiSewa is an unvalidated early-stage product.

## Decision

Start with Jwala Nagar, Shahdara, Delhi 110032.

## Reasoning

A small geographic area allows the project to:

- Understand residents closely
- Interact directly with local businesses
- Build local data density
- Maintain better data quality
- Learn quickly
- Keep operational complexity manageable

## Alternative Options

- Entire Delhi
- Shahdara
- Multiple neighborhoods

## Revisit When

There is sufficient evidence that the product is useful locally and that expansion can be supported operationally.
