# DelhiSewa

> Hyperlocal discovery platform starting with Jwala Nagar, Shahdara, Delhi 110032.

---

## Current Phase

**Phase:** Pre-MVP / Validation

**Initial Geography:** Jwala Nagar

**Primary Objective:**

Validate whether residents find value in an organized digital platform for discovering local businesses, shops, services, professionals, and useful places.

## Important Principles

1. Start local.
2. Build for real users.
3. Talk to businesses.
4. Prefer evidence over assumptions.
5. Keep the MVP simple.
6. Avoid premature complexity.
7. Expand only when the evidence supports expansion.
