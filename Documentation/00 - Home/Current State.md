# Current State

## Date

2026-08-13

## Product Stage

Pre-MVP / Validation

## Geography

Jwala Nagar, Shahdara, Delhi 110032

## Product

The first version is intended to provide organized discovery of:

- Businesses
- Shops
- Services
- Professionals
- Useful local places

## What We Know

- DelhiSewa is starting with a deliberately small geographic area.
- The first version should remain simple.
- Real user and business feedback will determine future development.

## What We Do Not Know Yet

- Which discovery use cases are most valuable.
- Which categories have the strongest demand.
- How frequently residents will use the platform.
- What information businesses are willing to provide.
- What business model, if any, should eventually be used.
- What evidence should trigger geographic expansion.

## Current Priorities

1. Define the MVP.
2. Research local residents.
3. Research local businesses.
4. Build useful initial data.
5. Build the first usable product.
6. Test with real users.

## Current Risks

- Building too much before validating demand.
- Insufficient quality or coverage of local listings.
- Difficulty getting businesses to participate.
- Building features users do not need.
- Expanding geography before achieving local usefulness.

Update this document whenever the fundamental state of the project changes.
