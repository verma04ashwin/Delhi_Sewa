# DelhiSewa Data

Operational data and data tooling for DelhiSewa.

## Structure

- `raw/` — Original/raw data
- `processed/` — Processed data
- `imports/` — Import files
- `exports/` — Exported files
- `scripts/` — Data-related scripts

Operational data should not be treated as product documentation.
